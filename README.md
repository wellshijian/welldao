## ✨ 核心功能

- **💰 今日窝囊费（独家特色）**：支持自定义月薪、工作制（双休/大小周/单休/全勤）、上下班时间与发薪日；实时跳动计算今日已挣窝囊费、打工进度条、下班倒计时与发粮倒计时，支持顶部胶囊轮播或常驻显示，内置打工人趣味回血语录。
- **🌤️ 当地天气与日出日落**：实时显示当前天气与气温，支持七日预报与日出日落时间，顶部胶囊直观呈现。
- **🎵 音乐与桌面歌词**：自动识别系统正在播放的音乐（网易云音乐、QQ 音乐、酷狗、汽水音乐、Spotify、浏览器等），支持封面展示、进度控制与实时逐字歌词。
- **🍅 专注番茄钟与健康提醒**：自定义专注时长、喝水提醒、久坐提醒与午休免打扰，养成健康工作节奏。
- **📋 待办清单与临时置物架**：随手记录今日待办事项，拖拽文件到顶部灵动岛即可临时收纳与快速取用；支持剪贴板历史记录。
- **📅 通知、邮箱与日程**：支持微信、企业微信、飞书、钉钉、QQ 新消息提醒与一键唤起、多邮箱验证码自动提取、月历与工作日程同步。
- **🤖 AI 额度监控**：直观查看常用 AI 工具（Claude、Codex、Gemini、DeepSeek、Grok、豆包、Kiro 等）剩余额度状态。
- **🚀 国内免代理极速更新**：内置多通道国内高速更新节点与 SHA-256 安全校验，点击「检查更新」即可一键秒速在线升级。

## 📦 下载与安装

前往 **[GitHub Releases 最新版页面](https://github.com/wellshijian/welldao/releases/latest)** 选择适合您的版本：

| 安装包文件名 | 说明 |
| :--- | :--- |
| **`wellshijian-Setup.exe`** | **推荐（安装版）**。双击即可安装或覆盖升级，自动配置桌面快捷方式与开机自启。 |
| **`wellshijian-portable.zip`** | **免安装便携版**。解压后直接运行 `wellshijian.exe` 即可使用。 |

## 🔒 隐私与数据存储

- 所有个人配置、待办清单、窝囊费参数、健康记录均保存在本机 `%APPDATA%\wellshijian` 目录下，覆盖更新或重装均会自动保留原有数据。
- 邮箱密码、和风天气 Key 与接口凭据通过系统级 Windows 凭据管理器加密存储。
